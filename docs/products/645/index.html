製品備考
2005年4月発売の初版
箱の商品名はAE86だが、車両後部にAE85の1.5 SRグレード表記がタンポ印刷されていた。
発売後に回収対象となり、希望者は同年8月中に修正版と交換できた。
修正版ではリアのグレード表記を「1.5 SR」から「APEX」へ変更し、リアのナンバープレート周囲を黒く塗装している。
修正版は同年9月より再販された。
